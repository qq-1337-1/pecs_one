This is a application that for PECS (Picture Exchange Communication System) cards.

Each PECS card here is represented by

1) vector image
2) name text


This application provides 
1. "Board" page to arrange PECS cards
2. "Cards" page to manage PECS cards
3. "Editor" page with editor/creator for PECS cards

#### build project

npx vite build --minify false

#### run app

npm install
npm run dev
